# Getting Started

Welcome to the **Artifact Browser** sample data set.

## Features

1. Browse folders using the sidebar tree or breadcrumb
2. Preview Markdown, text, image, audio, and video files
3. Search recursively across the artifact tree
4. Select multiple files and download them as a ZIP archive

> Note: this deployment is strictly read-only. Uploads and edits are out of scope.
